How to use this with the ha-ipixel-color integration in Home Assistant:

1. Install Integration

In Home Assistant HACS → Custom repositories → Add: https://github.com/jeryci/ha-ipixel-color-gifgen as an Integration.

2. Host this Tool inside Home Assistant

Place this app directory into your HA /config/www/matrix-resizer/ folder.

3. Add to Sidebar (Modern HA 2024.4+)

Go to Settings → Dashboards → Add Dashboard → select Webpage:

  • Title: Matrix PixelForge
  • Icon: mdi:led-strip-variant
  • URL: /local/matrix-resizer/index.html
  • Show in sidebar: ✅ Yes
Home Assistant Automation / Script (Text & Display Mode) 
# Home Assistant iPIXEL Color Control
service: ipixel_color.display_text
target:
  entity_id: text.ipixel_display
data:
  text: "{{ states('sensor.temperature') }}°C"
  effect: "static"
